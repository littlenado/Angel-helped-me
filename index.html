v86 Chromebook Workspace

Serve this folder over HTTP (e.g. python3 -m http.server) and the engine + firmware load automatically — you only pick a disk / ISO.
Opened straight from disk (file://)? Pick the three files in section 1 by hand.

1. System Binaries & Firmware (auto-loaded over HTTP)

2. Disks: floppy, CD/DVD and hard drives

Each file is sent to the right drive: floppy, CD/DVD or hard disk.
Blank disks start empty and cost no storage: only what the OS writes is kept, in memory, so everything on them is lost when you press Stop or close the page. Windows 2000/XP Setup can partition and format a blank disk itself (pick the quick format). Windows 95/98 need FDISK and FORMAT first. Installing XP can use 1-2 GB of memory on top of the emulator's own.

4. Hardware

MB
CPU cores: 1. v86 emulates a single x86 processor, so there is no core count to change. The cap limits how much of your computer's CPU time the PC may use; it cannot make the PC faster than your computer allows.
RAM, video memory and the JIT switch take effect at the next boot. A resumed PC always uses the RAM and video memory it was saved with.

5. Saved PC

Stores the machine's memory and everything written to its disks inside this browser, so closing the tab doesn't lose your install.
